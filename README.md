# 🧠 ZukkAI — Informatika Fanida Sun'iy Intellekt Tizimi

**ZukkAI** — bu Informatika fanini o'qitishda zamonaviy pedagogik metodikalar va sun'iy intellekt (AI) texnologiyalarini integratsiya qiluvchi innovatsion platforma. Platforma o'qituvchilarga interaktiv topshiriqlar yaratishda va o'quvchilar bilimini xolis baholashda yordam beradi.

---

## 📋 Loyihaning Metodik Asosi

Ushbu platforma ilmiy tadqiqot ishidagi quyidagi boblar asosida ishlab chiqilgan:
*   **2.1-§.** Informatika darslarida SI yordamida interaktiv topshiriqlar yaratish metodikasi.
*   **2.2-§.** O‘quvchilar bilimini avtomatik baholash va qayta aloqa (feedback) tizimini shakllantirish.
*   **2.3-§.** O‘tkazilgan tajriba-sinov ishlari natijalari va samaradorlik tahlili.

---

## ✨ Asosiy Imkoniyatlar

- 🚀 **AI Task Generator:** Informatika fanining istalgan mavzusida (Algoritmlash, Python, SQL va h.k.) 3 xil murakkablik darajasidagi topshiriqlarni lahzalarda yaratish.
- 🤖 **Auto-Assessment:** O'quvchilar yuborgan javoblarni Google Gemini 1.5 Pro/Flash yordamida tahlil qilish va 100 ballik tizimda baholash.
- 💬 **Intelligent Feedback:** AI o'quvchining xatolarini tushuntirib beradi va metodik tavsiyalar taqdim etadi.
- 📊 **Dashboard & Analytics:** O'quvchining barcha yutuqlari va o'rtacha ballari jamlangan shaxsiy profil.
- 📱 **Responsive Design:** Platforma barcha qurilmalarda (Mobil, Planshet, Kompyuter) ideal darajada ishlaydi.

---

## 🛠 Texnologik Stek

*   **Backend:** Python 3.12, Django 5.x/6.x
*   **Frontend:** Tailwind CSS, Alpine.js (Loading states & Modals)
*   **AI Engine:** Google Gemini AI API
*   **Database:** SQLite (Dastlabki bosqichda)
*   **Design:** Modern Clean UI (Apple-style)
